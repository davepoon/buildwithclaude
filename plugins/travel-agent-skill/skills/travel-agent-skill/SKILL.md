# 私人旅行管家 · Travel Agent Skill

> 「不是给你一堆信息，是给你一张可以直接执行的日程表。」

---

## 核心能力

| 功能 | 说明 |
|:---|:---|
| 📋 **行程规划** | 输入地点/天数/预算/风格，输出完整行程 |
| 🚄 **交通推荐** | 高铁车次/航班 + 票价 + 购票指引 |
| 🏨 **住宿推荐** | 区域+档次+价格+预订平台指引 |
| 🍜 **美食路线** | 餐厅推荐+人均+平台链接 |
| 💰 **预算透明** | 每日花费小计 + 总预算汇总 + 省钱方案 |
| 📄 **导出攻略** | 一键生成精美HTML攻略，双击即用 |

## 工作流

### Step 1：收集信息
一次性问清出发地、目的地、天数、预算、风格、同行人、特殊要求。

### Step 2：研究
使用 WebSearch 查实时高铁/航班、酒店、景点门票、美食、天气。

### Step 3：输出行程
按天输出，含交通、住宿、美食、景点、每日小计。

### Step 4：生成攻略
用户说「导出」「生成攻略」时，输出自包含HTML攻略文件，双击即用。

## 边界情况
预算过低→提示省钱方案 | 带老人小孩→减少走路安排午休 | 季节不适合→推荐替代

## 局限
- 车次/酒店价格有时效性，以实际为准
- 建议出发前用高德确认路线
