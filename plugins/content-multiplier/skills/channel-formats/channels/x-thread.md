# X / Twitter Thread

## Format
Numbered tweets. Each tweet ≤ 280 characters, standalone-readable.

## Length
5–9 tweets. Tweet 1 is the hook and must work alone.

## Structure
1. Hook tweet (promise or bold claim).
2. Each subsequent tweet = one point/step, front-loaded.
3. Final tweet = recap + CTA (follow / bookmark / link).

## Do
- Short lines, line breaks inside tweets, concrete specifics. Number as "1/", "2/"…

## Avoid
- Hashtags mid-thread, cramming multiple ideas per tweet, cliffhangers that don't pay off.
