# Short-Video Script (TikTok / Reels / Shorts)

## Format
Spoken script with on-screen text cues and a hook callout. Written for 20–45 seconds.

## Length
80–150 words of spoken content. Hook must land in the first 3 seconds.

## Structure
1. HOOK (first line, on-screen text + spoken).
2. Beats: 3–5 quick spoken lines, each with an on-screen text cue in [brackets].
3. Payoff + CTA (follow / comment / link in bio).

## Do
- Punchy, verbal, second person. Mark [on-screen text] cues.

## Avoid
- Slow intros, jargon, more than one CTA, scripts longer than ~45 seconds of speech.
