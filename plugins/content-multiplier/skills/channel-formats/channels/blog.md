# Blog Post / Excerpt

## Format
Markdown with H2/H3 subheads, short paragraphs, optional bullet lists.

## Length
Excerpt 150–250 words; short post 500–800 words. Include a title and meta description (≤ 155 chars).

## Structure
1. Title + meta description.
2. Intro that states the payoff.
3. 2–4 subhead sections.
4. Conclusion + CTA.

## Do
- One idea per section, descriptive subheads, skimmable formatting.

## Avoid
- Keyword stuffing, giant paragraphs, subheads that don't describe their section.
