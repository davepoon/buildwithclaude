# Newsletter Section

## Format
Email-friendly: short paragraphs, one clear CTA, scannable subheads.

## Length
150–350 words. Plus a subject line (≤ 50 chars) and preview text (≤ 90 chars).

## Structure
1. Subject line + preview text.
2. Opening line that pays off the subject.
3. Body: 2–4 short paragraphs or a mini-list.
4. One primary CTA button/line.

## Do
- Write to one reader ("you"). Deliver value before the ask.

## Avoid
- Multiple competing CTAs, long unbroken paragraphs, clickbait subjects that don't match the body.
