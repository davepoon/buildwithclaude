# YouTube Description + Chapters

## Format
Video description text plus timestamped chapter list.

## Length
Description 200–500 words. First 1–2 lines (~100 chars) show above the fold.

## Structure
1. 1–2 line hook summarizing the video's payoff.
2. Short paragraph of context.
3. Chapters: `0:00 Intro`, `1:24 <topic>` … (first timestamp MUST be 0:00).
4. CTA + relevant links section.

## Do
- Front-load keywords naturally, keep chapter titles concrete.

## Avoid
- Keyword stuffing, fake timestamps, missing the 0:00 chapter.
