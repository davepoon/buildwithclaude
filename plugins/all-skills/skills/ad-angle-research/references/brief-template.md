# Ad angle brief structure

1. **Scope:** competitor domain, as-of date, source mode (connector / manual sample), counts per source and anything not checked.
2. **Proven angles (oldest active first), up to three:** hook (quoted) · offer · CTA · landing URL · running since · format · placements · Ad Library link.
3. **Landing pages:** URL · number of ads pointing at it · what the page sells (one line).
4. **Mix in one line:** formats, platforms, Google presence and since when.
5. **Tests for the user, up to three:** observed ad → hypothesis for the user's product → smallest test → asset or offer prerequisite → success measure → stop point.
6. **Unverified:** sources that returned `null`, pages not opened, claims in ad copy left unchecked.

Keep quotes short and attributed. Omit empty sections. A brief with three real angles beats a list of twenty ads.
