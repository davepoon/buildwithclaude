# Manual route (no connector)

Both libraries are public. Walk the user through them rather than guessing.

**Meta Ad Library** — `https://www.facebook.com/ads/library/?active_status=active&ad_type=all&country=US&q=<domain>&search_type=keyword_unordered&media_type=all`. Ask the user to open it (or open it with the host's browser tool if one exists), filter to active ads, and paste back for the oldest five: start date, headline, first two lines of body, CTA, landing URL, and the ad's library link (`?id=`). Note the page name; keyword search can surface affiliates.

**Google Ads Transparency Center** — `https://adstransparency.google.com/?domain=<domain>&region=US`. Record advertiser name, formats present, earliest "first shown" date, and whether ads are region-limited. Copy is usually not exposed; do not infer it.

Label the brief as manual-sample-only and state how many ads were reviewed. The manual route cannot give counts across all active ads; say so instead of estimating.
