# Browser Extension Launch

Canonical source: https://github.com/xiehuan123/browser-extension-launch

MIT-licensed shared skill for building Chrome Manifest V3 extensions from plain-language requirements. This copy preserves the source instructions, references, helper scripts, starter assets, and license. Its only skill-entry adaptation is the category required by this collection.

Runtime requires file and shell access and a verified extension-capable controlled browser. Installation has been exercised for Claude Code, but a complete Claude Code runtime acceptance run is not claimed. Public extension examples were verified through Codex CLI sessions.

Examples: build a local page color picker; diagnose an existing extension; prepare release materials after actual browser acceptance. Source completion, browser acceptance, store submission, and public availability remain separate states.
