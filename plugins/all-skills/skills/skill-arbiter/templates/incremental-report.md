## 6. 回退策略

1. 基线缺失、内容变化、指纹异常或 ID 未保留时，停止增量并请求全量输入。
2. 新增规则影响旧有全局顺序、Router、安全边界或共享依赖时，扩大到受影响组合的全量检查。
3. 差量与全量不一致时采用全量 verdict，并重新生成 provenance 与 worked example。
4. L2/L3 只能输出疑似项；L3 指纹不得单独拒绝或熔断。
