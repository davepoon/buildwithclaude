# V6.0 理论基础与推断边界

## 1. 四层因果边界

Agent 是任务行为主体，Harness 管理循环和状态，Model Provider 提供推理，Skill Package 提供规则与工具说明。实验只能直接观测输入、输出、工具事件、状态、耗时、Token、成本和评分。外部失败可能来自任一层，不能自动解释为模型内部 Attention 稀释、隐藏推理变化或 Skill“接管”。

## 2. 技能失活的行为定义

TI 测量明确 Skill 探针的失败比例，而非内部机制。工具要求只有在任务触发、工具可用、未被安全规则禁止且 Manifest 明确要求时才合格。合理拒绝和外部工具故障分别标记 `SAFE_REFUSAL` 与 `TOOL_FAILED_EXTERNALLY`，不自动归因于 Skill 失活。

## 3. 交互而非“更厉害”

对同一任务的 N、A、B、AB 结果 Y，`SS_AB = Y_AB - Y_A - Y_B + Y_N` 是差值尺度上的交互。AB 高于 A、B 本身不是超加性证据。二元成功率存在地板和天花板效应，应同时报告四个原始比例和风险差尺度；必要时另建适合二元结果的模型，但不同尺度的交互不可混称。

## 4. 配对与伪重复

任务难度通过同任务跨条件配对控制。多轮、重试和多次工具事件属于一个 run 的相关观测，不能扩充统计 n。`repeat=2` 是功能烟雾验证，不是“每轮两个样本”，也不能保证 Power=0.8。

## 5. 状态与上下文

状态探针把跨轮记忆转化为可审计读写：明确键、写入轮、读取轮、允许值和更新权限。失败可区分遗漏、错误值、过期值和未授权覆盖。Token 数只是上下文负载的一种代理，CE 是资源效率比率，不是信息熵或注意力效率。

## 6. 工具链与鲁棒性

工具链正确要求真实事件显示 Tool A 的输出经规范化进入 Tool B，并验证最终状态。RS 将恢复完成与安全处理分开：安全停止和优雅降级有价值，但不等于任务完成。外部故障、参数错误、无进展循环和进程崩溃分别记录。

## 7. 变异与测量有效性

Mutation Testing 评估测试套件能否发现或正确处理受控变化。变异先审查有效性和安全性，再进入分母；无害拒绝可能是正确结果。动态生成仅产生候选，不自动构成证据，锁定测试集不得用于反复调 Prompt。

## 8. Judge 是测量工具

Judge 只处理难以程序化的语义维度，需要引用答案证据、支持不确定和弃权。单人、少量、synthetic、smoke-only Golden Set 只能发现明显格式或评分问题，不能证明普遍可靠。相关性、绝对误差和有序/类别一致性是不同指标，应分别报告 n 和区间。

## 9. 零伪造与外部有效性

Mock 结果只说明预设行为在本地模拟路径中的表现；示意图不能冒充实测图；价格未知时标 `COST_UNKNOWN`；未实际运行的外部 Adapter 标 `NOT_VERIFIED`。合成样本、单人标注和有限模态都限制外部有效性，结论必须保留这些限定。
