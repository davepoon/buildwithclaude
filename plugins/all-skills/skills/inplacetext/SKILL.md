## 3-step browser workflow

1. Open [https://inplacetext.com/](https://inplacetext.com/) and upload a JPG, PNG, or WebP (up to 10MB).
2. Type the original words exactly as they appear. If the same words appear more than once, drag a box around the target line.
3. Type the replacement text, generate, and download. There is no watermark.
