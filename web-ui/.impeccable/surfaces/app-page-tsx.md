Scope: homepage (`app/page.tsx`, `app/page-client.tsx`). Mode: Persuade toward one action, searching or opening an item. Established world; structure chosen by the user (centered search + ticker + leaderboards), no concept roll.

Audience and job: a Claude user looking for something to install, or checking what is popular and new.

## Direction contract

THESIS: The homepage is a live index, not a pitch for our marketplace. It refuses the split hero with a product mockup.

OWN-WORLD: Incumbent system unchanged: near-black ground, terracotta accent, Instrument Serif headings, Outfit body, JetBrains Mono only for numbers and commands. Rows and hairlines instead of card grids; the old hero's wavy terracotta strokes return as a faint backdrop.

STORY: Visitor sees everything is searchable here, sees what others are installing right now, opens an item.

FIRST VIEWPORT: Centered headline, one large search field in the middle of the page, a row of type shortcuts with counts under it, then a full-width moving ticker of ranked items closing the fold.

FORM: User-locked structure "Centered search + ticker"; seed: none (unavailable). Signature interaction: the ticker (pauses on hover and focus, static and scrollable under reduced motion). Below: tabbed leaderboard by real signal with a "Just added" rail, themes, daily rotating picks for types without signals, stories, one quiet marketplace command line.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
