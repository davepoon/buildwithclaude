# Community theme previews

These SVGs are illustrative previews drawn for this site, not screenshots. Each one is a
simplified mock-up coloured with the palette its theme publishes in its own repository:

| File | Theme | Source of the colours |
| --- | --- | --- |
| `one-dark-pro.svg` | One Dark Pro | https://github.com/Verschnupft/claude-one-dark-pro |
| `aurora.svg` | Aurora | https://github.com/00015972/claude-aurora |
| `bubblegum-fizz.svg` | Bubblegum Fizz | https://github.com/HemalathaMadeswaran18/bubblegum-fizz |
| `deutan-cvd.svg` | Deutan Dark and Deutan Light | https://github.com/chrisathook/claude-code-cli-themes |

They stand in until a theme's author adds a real screenshot. To replace one, point the
theme's `preview` in `web-ui/lib/themes.json` at an image in the author's repository.
